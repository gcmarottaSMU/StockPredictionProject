# StockPredictionProject
# Stock Price Prediction with RNNs (CS 5393 Final Project)

Comparing LSTM and GRU models (using TensorFlow/Keras) for predicting AAPL stock prices based on historical data ('Close' price and 'Volume').

## Setup

1.  **Python:** This code was tested successfully using **Python 3.11**.
2.  **Libraries:** Install the required packages.
    ```bash
    pip install tensorflow yfinance pandas numpy scikit-learn
    ```

## Running

Make sure you have activated your virtual environment (if using one), then run:

```bash
python stock_predictor.py
